SUBSYSTEM ARCHITECTURE

Core Subsystems

Architectural decisions engineered for durability, data privacy, and instantaneous local performance.

SPEC 01 / PERSISTENCE

Local Database

Structured on embedded SQLite 3.45 with Write-Ahead Logging (WAL) mode. Utilizes strictly scoped Android app-private storage (/data/user/0/com.treen.task/). Zero external storage permissions requested (READ/WRITE_EXTERNAL_STORAGE: NO).

ZERO PERMISSIONS · ATOMIC DISK WRITES
SPEC 02 / CRYPTOGRAPHY

Tamper-Proof Vault

Backups use an authenticated Encrypt-then-MAC construction: AES-256-CBC encryption followed by an HMAC-SHA256 signature calculated over the ciphertext. Modifications made outside the app in a text editor invalidate the signature immediately.

PIPELINE: AES-256 (CBC) + HMAC-SHA256
SPEC 03 / EFFICIENCY

Binary Footprint

Ahead-Of-Time (AOT) compiled native code with native C-SQLite bindings. Fonts are tree-shaken and all 36 collection vector assets are compressed by 75.5% (< 420 KB total). Total binary distribution remains comfortably under 25MB (8.4 MB core).

AOT COMPILED · < 25MB TOTAL BINARY

AUTHENTICATED BACKUP VERIFICATION

The Encrypt-then-MAC Pipeline

When restoring a .popvault archive, Treen verifies the HMAC-SHA256 signature before decrypting the payload. If any record (such as an artificially altered streak) was modified, verification fails immediately.

DATABASE ARCHITECTURE

Production SQLite Schema

Transparent DDL table definitions compiled into tasks.db.

-- Treen Task SQLite DDL (Engine Version 1.4.2)
CREATE TABLE IF NOT EXISTS tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  completed INTEGER DEFAULT 0,
  tag TEXT DEFAULT 'CORE',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  certified_at TIMESTAMP
);

CREATE TABLE IF NOT EXISTS daily_capsules (
  date_iso TEXT PRIMARY KEY,
  tasks_completed_count INTEGER DEFAULT 0,
  gate_passed INTEGER DEFAULT 0,
  active_collection TEXT NOT NULL,
  milestone_badge_awarded TEXT
);

CREATE TABLE IF NOT EXISTS vault_snapshots (
  snapshot_hash TEXT PRIMARY KEY,
  streak_record INTEGER NOT NULL,
  hmac_signature TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
