DAILY PROTOCOL ARCHITECTURE

The 3-Task Milestone Engine

Habit formation fails when systems allow fractional, meaningless checkmarks. Treen Task enforces a binary contract: three daily accomplishments before midnight, or your streak dissolves.

1 THE MANDATORY THRESHOLD

The 3-Task Gate

Completing one or two tasks earns zero streak momentum and zero stickers. You must reach $\ge 3$ tasks completed within the calendar day to prime the verification engine. Quality over infinite trivial task lists.

2 CHRONO-SYNCHRONIZATION

The Midnight Rollover (11:59 PM)

At 23:59:59 local device time, an automated SQLite trigger evaluates the daily register. If the gate was reached ($\ge 3$), the streak counter increments by +1. If incomplete, the streak is uncompromisingly reset to zero.

3 ARCHIVAL TRADITION

Next-Day Morning Reveal

Your achievement is not blared with annoying push notifications. Instead, upon opening Treen the following morning, you are greeted with a quiet Japanese stationery embossed stamp and your newly unlocked universe sticker.

CRYPTOGRAPHIC ARCHITECTURE

The Tamper-Proof Vault (.popvault)

Most offline apps store backups in cleartext JSON or simple ZIPs, making streak forgery trivial with any text editor. In Treen, your streak is a contract with yourself backed by authenticated cryptographic validation.

AUTHENTICATED ENCRYPTION PIPELINE
JSON Payload
AES-256 (CBC) ⟶
Ciphertext
HMAC-SHA256 ⟶
.popvault Container

Hardware-Seeded Entropy Key

When Treen initializes, it computes a device-unique cryptographic seed using native hardware entropy (Android Keystore / hardware token). No plain master keys are ever written to unencrypted storage.

Anti-Cheat HMAC Signature Verification

When you restore a .popvault backup, the engine recomputes the HMAC-SHA256 signature over the payload. If even a single byte (such as changing "streak_count": 14 to 999) was edited in a text editor, the signature will violently fail verification and the backup is quarantined.

Zero Cloud Synchronization Risk

Your encrypted backups belong to you. Store them on a micro-SD card, send them via local Bluetooth, or keep them on a USB key. No third-party SaaS company can ever read, delete, or harvest your daily journals.

          DDL SPECIFICATION
        

        


-- Immutable local schema for Treen Task
CREATE TABLE IF NOT EXISTS tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  completed INTEGER DEFAULT 0,
  tag TEXT DEFAULT 'CORE',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  certified_at TIMESTAMP
);

CREATE TABLE IF NOT EXISTS daily_capsules (
  date_iso TEXT PRIMARY KEY,
  tasks_completed_count INTEGER DEFAULT 0,
  gate_passed INTEGER DEFAULT 0,
  active_universe TEXT NOT NULL,
  sticker_awarded TEXT
);

CREATE TABLE IF NOT EXISTS vault_snapshots (
  snapshot_hash TEXT PRIMARY KEY,
  streak_record INTEGER NOT NULL,
  hmac_signature TEXT NOT NULL,
  exported_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
