PHILOSOPHY & SYSTEM OVERVIEW

Quiet, sovereign utilities for deliberate work.

Treen is an ecosystem of self-contained local software tools designed around Japanese stationery traditions and strict data sovereignty. No remote databases, zero third-party telemetry, and zero storage permissions. Built for individuals who prefer silent instruments over noisy platforms.

FOUNDATIONAL PILLARS

Engineered for quiet longevity.

Three architectural constraints govern every tool created under the Treen specification.

01 / LOCAL PERSISTENCE

Offline by Default (SQLite)

Structured on embedded SQLite 3.45 with Write-Ahead Logging (WAL). All state writes execute instantly on local metal with zero background telemetry beacons.

SPEC: PURE SQLITE 3.45 · 0 NETWORK CALLS
02 / CRYPTOGRAPHIC SECURITY

Data Ownership (.popvault)

Backups are encrypted via AES-256-CBC and authenticated with HMAC-SHA256 signatures. Modifications outside the app invalidate the signature immediately.

SPEC: ENCRYPT-THEN-MAC (AES-256 + HMAC)
03 / CALM INTERACTION

Calm Interfaces

Archival paper aesthetic (#FAF9F6) designed to reduce screen fatigue, eliminate notification friction, and restore an analog cadence to digital execution.

SPEC: ZERO AD-TECH · ZERO ENGAGEMENT TRAPS
