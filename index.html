PHILOSOPHY & SYSTEM OVERVIEW

Quiet, sovereign utilities for deliberate work.

Treen is an ecosystem of self-contained local software tools designed around Japanese stationery traditions and strict data sovereignty. No remote databases, zero third-party telemetry, and zero storage permissions. Built for individuals who prefer silent instruments over noisy platforms.

FOUNDATIONAL TENETS

Engineered for quiet longevity.

Three architectural constraints govern every tool created under the Treen specification.

01 / OFFLINE ARCHITECTURE

Offline by Default

Structured on embedded SQLite 3.45 with Write-Ahead Logging (WAL). All state writes execute instantly on local storage. No background network pings, no telemetry beacons, and zero dependence on remote cloud clusters.

SPEC: 0 HTTP CLIENTS · 0 NETWORK CALLS
02 / CRYPTOGRAPHIC SECURITY

Complete Data Ownership

Backups are serialized into authenticated .popvault containers. Encrypted with AES-256-CBC and signed with hardware-bound HMAC-SHA256. Your history stays on your metal, impervious to unauthorized modification.

SPEC: ENCRYPT-THEN-MAC (AES-256 + HMAC)
03 / CALM INTERACTION

Calm Interfaces

Typeset on a warm archival paper surface (#FAF9F6) with dense broadsheet typography. Designed to reduce ocular fatigue, eliminate push notification friction, and restore software to an analog cadence.

SPEC: ZERO AD-TECH · ZERO ENGAGEMENT TRAPS
